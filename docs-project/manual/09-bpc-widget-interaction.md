<!-- DOCBLOCK id="p-component-widget-interaction-parameters-0" type="text" -->
<!-- ZH -->
检测通道
设置检测 UI 时使用的碰撞通道，需要与目标 UI 的碰撞响应对应。
交互距离
设置手指触碰 UI 的有效检测距离，超出距离时不触发交互。
指针索引
设置当前交互指针的编号，用于区分不同的交互指针，组件类别做了编号命名重叠的机制，会获取角色所有控件交互组件自动排序。
