<!-- EN -->

<!-- /DOCBLOCK -->

<!-- DOCBLOCK id="p-component-widget-interaction-ray-parameters-0" type="text" -->
<!-- ZH -->
显示调试
开启后显示控件交互的调试信息，方便检查射线检测与命中位置。
插值缓动速度
设置射线跟随手部或控制器移动时的平滑速度，数值越大跟随缓动越大。
命中 UI圆初始缩放
设置射线命中 UI 时UMG圆的基础缩放大小。
射线有效距离
设置射线响应 UI 的有效距离范围。(最短距离，最远距离）
手柄角色注意，需要绑定一个输入，用于触发鼠标左键按压，布尔控制按下左键和松开左键
