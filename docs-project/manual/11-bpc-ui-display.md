<!-- ZH -->
是否开启调试？
开启后显示位置与朝向调试辅助信息，方便调整 UI 的显示位置和检测方向。
显示的UI
选择要生成并显示的 UI 蓝图类，这里使用的是包含 UI 的 Actor 蓝图。
设置箭头位置
设置显示检测参考箭头的相对位置，箭头是触发器，看向箭头才会触发UI,一般箭头位置在掌心。
摄像头检测箭头
设置摄像头是否朝向参考箭头的检测阈值。
箭头检测摄像头
设置参考箭头是否朝向摄像头的检测阈值。
