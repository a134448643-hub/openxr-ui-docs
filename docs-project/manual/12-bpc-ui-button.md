按钮名称
设置按钮上显示的文字。
按钮图像
设置按钮显示的图像纹理。
最小按压距离（x轴）
设置按钮沿自身 X 轴完成按压所需的距离，用于调整按钮的触发深度。

完成按压时
按钮达到设定的按压深度、完成按压时触发，可绑定需要执行的按钮功能。
取消按压时
取消按压并让按钮回弹时触发，可绑定松开按钮后的处理逻辑。
